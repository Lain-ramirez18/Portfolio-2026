---

## 🚀 Características Principales

- **Diseño Adaptativo (Responsive Design):** Optimizado para dispositivos móviles, tablets y escritorio.
- **Soporte Multi-idioma:** Alternancia instantánea entre **Español (ES)** e **Inglés (EN)** sin recargar la página.
- **Modo Oscuro/Claro:** Implementación nativa de temas visuales para mayor comodidad del usuario.
- **Efecto "Anti-gravity" (Parallax):** Animación interactiva de seguimiento de mouse en la foto de perfil.
- **Reveal on Scroll:** Animaciones suaves de entrada para elementos de experiencia, aptitudes y proyectos al hacer scroll.
- **Estética Material Design 3:** Inspirado en las guías de diseño de Google para una apariencia limpia y profesional.

---

## 🛠️ Stack Tecnológico

- **Frontend:** HTML5 (Living Standard), CSS3 (Moderno), JavaScript Vanilla (ES6+).
- **Tipografía:** Inter (Google Fonts).
- **Iconografía:** Emojis y símbolos Unicode para un estilo minimalista.
- **Herramientas de IA (Integradas en Proyectos):** Groq API, Llama 3, Prompt Engineering avanzado.
